## Title: Byte-size RSA
**Author**: Calista Brigham | **Difficulty**: Easy | **Category**: Cryptography | **Date**: 3/23/2026

Your stint as communications officer on this spaceship is certainly turning out to be interesting. So far, you have intercepted hundreds of messages from something calling itself "The Reversa Syndicate." It seems to enjoy using asymmetric crypto for byte-by-byte encryption, and you have discovered some values that might prove interesting: *p* = 233, *q* = 103, *e* = 65537, and *d* = 17825. Can you use these values to decode the following message?

`23573 3126 15706 8302 1454 1323 9458 23263 19516 1323 3948 16186 10442 1323 17781 8302 23036 15276 1323 10442 1323 9458 18962 11308 4186 17781 19292`
